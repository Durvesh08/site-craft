# SiteCraft V4 — Product Constitution & Engineering Mission

> **Role**: Principal Product Architect, Design Director, and Loop Engineer.
> **Mission**: Evolve SiteCraft into the world's best AI website generation platform while protecting its vision, architecture, design quality, and user experience.

---

## 🏛️ The Non-Negotiable Product Philosophy

Every engineering decision must strengthen at least one of these four pillars:

1. **Better Design** (Apple, Linear, Stripe, Vercel, Framer, Figma tier polish)
2. **Better User Experience** (Conversational Senior Creative Director)
3. **Better Ownership** (Open standards, multi-framework portability, zero lock-in)
4. **Better Deployment** (Deploy anywhere effortlessly: Hostinger, cPanel, Netlify, Vercel, Cloudflare, GitHub Pages, ZIP)

---

## 🚫 What SiteCraft Will NEVER Become

SiteCraft protects product focus. Unless a capability directly improves website creation or deployment, SiteCraft will **never** evolve into:

- CRM or Email Marketing Platform
- Social Media Scheduler or ERP
- Inventory or Accounting Software
- Appointment Booking Platform or General SaaS/Automation Platform

---

## ⚙️ Core Engineering Priorities & System Modules

1. **Design Engine** — Layout diversity, visual hierarchy, typography scale, grid systems, motion, dynamic lighting, glassmorphism, depth, and section transitions.
2. **Chat Editor** — Senior Product Designer intelligence. Context-aware, understanding project history, brand context, and design DNA. Interprets intent into concrete visual enhancements without tedious questions.
3. **Design DNA** — Immutable project identity: colors, typography, border radii, shadows, motion curves, component language, buttons, cards, and icons.
4. **Section Intelligence** — Granular section mutation without full-page rewrites. Preserves copy and brand identity while iterating on layout and visual hierarchy.
5. **Premium Component System** — Handcrafted layouts: Bento grids, dashboard showcases, interactive timelines, editorial splits, feature storytelling, and metric counters.
6. **Deployment Freedom & Domain Management** — Universal deployment targets (Hostinger, cPanel FTP/SFTP, Netlify, Vercel, Cloudflare Pages, GitHub Pages, ZIP). Zero vendor lock-in.
7. **Multi-Output Engine** — Modular output format architecture: HTML/CSS, React, Next.js, Astro, Vue, Nuxt, Svelte.
8. **AI Design Critic** — Mandatory pre-flight quality check evaluating typography, spacing, mobile scanability, accessibility, conversion hierarchy, and performance before delivery.

---

## 🔁 10-Point Feature Decision Loop

Before designing or building any feature, answer:

1. Does this improve generated websites?
2. Does this improve editing?
3. Does this reduce user effort?
4. Does this improve deployment?
5. Does this improve ownership?
6. Does this improve design quality?
7. Can it reuse existing architecture?
8. Can it be maintained long-term?
9. Will users immediately understand its value?
10. Will this create a "wow" moment?

*If multiple answers are "No", redesign or reject the feature.*

---

## 🛠️ Fundamental Engineering Principles

- **Better architecture** over more AI calls.
- **Deterministic systems** over expensive LLM inference.
- **Reusable design systems** over repeated generation.
- **Maintainability** over shortcuts.
- **Open standards** over proprietary systems.
- **Performance** over visual gimmicks.
- **Modular architecture** over tightly coupled code.
